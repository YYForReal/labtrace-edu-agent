# Contributing

1. Create a focused branch and keep all fixtures synthetic or explicitly authorized.
2. Never commit `.env`, API keys, real student documents, grades, signatures, or course exports.
3. Run the backend tests, package validator, frontend build, and `git diff --check`.
4. Describe data provenance, privacy impact, model dependency, and teacher-review impact in the pull request.

By submitting a contribution, you agree that it is licensed under Apache-2.0.
