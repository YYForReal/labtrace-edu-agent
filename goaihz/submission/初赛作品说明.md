# 格物智评 LabTrace

参赛队名：独立变量
参赛形式：单人
赛道：无界应用 / AI+教育
作品类别：面向高校教师的实验报告证据化批改 Agent

## 一句话价值

上传一份图文 Word，交还一份已批注、可编辑的 Word。

## 用户与痛点

首要用户是需要批改几十到数百份 Word/PDF 实验报告的高校教师与助教。实验报告包含正文、表格、代码、截图、结果图等混合证据，传统批改需要反复定位、判断、批注、登记和汇总。只输出一个分数或一段聊天回答，教师仍要把结果手工搬回 Word，既没有完成批改任务，也无法自然进入归档、返还和申诉流程。

## 可验证任务闭环

1. 教师使用内置六维标准，或上传真实课程 rubric JSON。
2. 上传已获授权的 DOCX/PDF，公开演示也可直接载入合成样例。
3. Agent 调用解析工具抽取正文、表格、图片及其在原 Word 中的位置。
4. 每个评分维度生成分数建议、理由、置信度和 evidence_id。
5. 低置信度、证据缺失或冲突项禁止自动发布，进入教师复核。
6. 教师确认或调整后，系统把证据批注、最终成绩和教师评语回写到可编辑 Word，并保留审计记录。
7. 系统只聚合已复核成绩，生成班级薄弱点和讲评建议。

## 当前已实现

- <https://yywebsite.cn/education/> 公共演示入口，无需登录或由评委提供模型密钥；
- 复用根项目 MiniMax-M3 配置，真实执行证据化逐项判断；输出经同一 `GradeTrace` 契约阻断幻觉证据、越界分和错误总分；
- 可上传教师课程 rubric JSON；模型不可用时显式降级到确定性基线；
- 报告文本在外部调用前自动替换可识别身份与联系方式；图片默认不外发，需教师单独勾选授权；
- 过敏原 ELISA 与 Unity 游戏开发双案例切换，68/75 为离线规则回归基线，不冒充真实模型固定输出；
- 过敏原离线回归为建议 68 分、分析维度 62% 低置信复核，教师把一项从 8 分调为 10 分后形成最终 70 分；
- 游戏开发离线回归为建议 75 分、分析维度 66% 低置信复核，真实模型同样需区分“运行成功”和“验证充分”；
- 图片证据以 `image:序号@paragraph:Word段落` 映射回原文档，在图片所在段落生成 Word 原生批注；
- 固定课程模板填写原有成绩/评语区；任意 Word 保留原文、表格和图片并追加标准批改页；
- 教师终审说明、最终成绩、原生 Word 批注和 GradeTrace JSON 均可下载复查；
- 4 份已复核合成样本的班级诊断：均分 73.5，最弱维度达成率 53%；
- 24 小时自动过期、立即删除、25 MiB 上传上限、限流与双任务并发保护；
- Docker 生产配置、18 项闭环/模型契约/图文 Word/隐私测试、双案例报告、初赛 PPT/PDF 和自然语音视频。

## 技术路线

- 前端：Vue 3、TypeScript、Vite、Element Plus；
- 后端：FastAPI、Pydantic、JSON 任务状态；
- Agent：MiniMax-M3 真实模型适配器 + 结构化证据契约 + 确定性降级；
- 文档：python-docx、PyMuPDF、LibreOffice；
- 模型：生产使用 MiniMax Anthropic 兼容端点；仍保留无密钥规则适配器和可替换协议边界；
- 部署：本地进程或 Docker Compose。

## 数据、隐私与教育边界

公开材料只使用人工合成数据。过敏原 ELISA 报告完全虚构，仅用于教学批改演示，不构成医学诊断；游戏开发报告参考真实课程任务结构重构，但学生正文、截图、身份、教师信息和运行记录均为人工合成。系统支持授权真实报告，但默认只向 MiniMax 发送自动脱敏后的有界文本证据与图片邻近文本；图片二进制必须由教师单独授权。系统是教师决策支持工具：AI 只给建议，正式成绩、评语和教学结论必须由教师确认。

## 当前验证与未验证项

已验证参赛模块 18/18 测试通过、MiniMax 真实 JSON 到 `GradeTrace` 映射、定向契约修复与 0/1 起始图片证据映射通过、双案例 FastAPI 完整复核闭环通过、教师终审后重新下载 Word 的评语/批注一致性、任意图文 Word 的原图片保留与通用批改页、非法伪装 PDF/DOCX 拒绝、任务路径不向浏览器泄露、公开合成数据隐私扫描。授权发送一张合成游戏截图的 MiniMax-M3 烟测也通过：图片计数为 1、无降级、证据契约有效。另以一份授权范围内的真实游戏开发报告和真实课程 rubric 完成脱敏文本烟测；这些单次烟测只证明工程兼容性，不作为准确率结论。

尚未验证真实教学准确率、教师一致性、真实样本总分 MAE 和节省时间比例。这些指标将在取得授权教师金标集后按预注册评测方案测量。

## 开放复用计划

通用 rubric、GradeTrace 契约、图文 Word 批改工具、合成数据、学情诊断、评测方法和复现文档已经迁移到独立公开仓库，并采用 Apache-2.0。原项目中的真实课程资料、学生数据和密钥不进入公开仓库；商业模型服务属于可选外部依赖，无密钥模式仍可复现教师任务闭环。
