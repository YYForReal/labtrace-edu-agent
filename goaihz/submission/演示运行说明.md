# LabTrace 初赛演示运行说明

## 推荐方式：公网真实模型演示

打开 <https://yywebsite.cn/education/>。无需登录，也不需要评委提供密钥；服务器使用未进入仓库/镜像的 MiniMax-M3 运行时密钥。公开站点提供一份合成任务书与两份合成图文报告，也接受 25 MiB 以内的授权 DOCX/PDF 和 256 KiB 以内的教师 rubric JSON。单个任务默认 24 小时自动删除，也可立即删除。

页面会显示本次到底是 `model_agent` 还是 `deterministic_fallback`、模型名称、耗时、Token、脱敏数量、检测/分析图片数，以及 Word 原生批注、图片批注、成绩和教师评语的回写状态。真实模型分数会随证据判断变化，不把 68/75 的规则回归分伪装为固定模型结论。

## 本地无密钥演示

环境要求：

- Python 3.11+；
- Node.js 20+；
- 已创建 `.venv` 并按根目录 `requirements.txt` 安装依赖；
- 首次运行前需要安装前端依赖。

在仓库根目录执行：

```bash
cd frontend
npm install
npm run build
cd ..

RUBRICS_DIR="$PWD/goaihz/config/rubrics" \
LABTRACE_RUNTIME_DIR="$PWD/goaihz/runtime/demo_tasks" \
LABTRACE_LLM_ENABLED=false \
PORT=11315 \
.venv/bin/python -m goaihz.app
```

打开 `http://127.0.0.1:11315/`。

该模式不需要模型密钥，真实执行 DOCX 解析、证据定位、评分校验、教师复核、Word 原生批注、成绩/教师评语回写和班级诊断。评分建议由公开确定性规则生成，页面会明确标注，不冒充大模型推理。

如需本地真实模型，将未提交的 `.env` 中同名 `LLM_*` 配置注入进程，并把 `LABTRACE_LLM_ENABLED` 设为 `true`。不要提交真实密钥。

## 三分钟演示步骤

1. 指出页面顶部的“MiniMax 真实 Agent”以及外部处理/教师终审边界。
2. 选择带合成运行截图的“Unity 弹射原型”Word，或载入一份授权的图文 Word；如需证明课程适配，再选择一个课程 rubric JSON。
3. 图片默认不外发；只有在材料授权清楚时才勾选图片分析同意框。
4. 点击“运行批改 Agent”，展示模型/耗时/Token/脱敏数量、`image:序号@paragraph:Word段落` 与逐项证据定位。
5. 说明每个正分必须引用已存在证据，契约失败不会进入发布界面。
6. 对最低置信度维度应用 +2 分示例或现场输入其他合法分，填写复核说明并确认。
7. 展示原始建议仍保留、最终分、学情诊断和教学动作。
8. 下载并打开可编辑 Word，确认原图、原生批注、最终成绩与教师终审说明均已写入；再下载 GradeTrace JSON 并立即删除任务。
9. 若现场模型超时，展示“显式降级”标识并继续相同教师闭环，证明系统没有伪造模型成功。

离线固定回归口径仍为：过敏原 68→教师 70、游戏开发 75；这些数字用于断网演示和测试，不代表真实模型准确率。

## Docker 方式

```bash
cp goaihz/.env.example goaihz/.env
docker compose -f goaihz/docker-compose.yml up --build
```

打开 `http://127.0.0.1:11315/`。

## 注意事项

- 不要将真实课程压缩包、学期数据、学生信息或生产日志用于公开演示。
- 现场不要展示 `.env`、模型密钥、内网 URL 或本地用户路径。
- 正式成绩必须由教师确认；真实模型和无密钥模式都不得自动发布。
- 未取得报告处理授权时只使用合成案例；不要把含身份的图片勾选外发。
- PDF 可参与解析与评分，但当前不承诺生成可保真的原位批注 Word；核心闭环以 DOCX 演示。
