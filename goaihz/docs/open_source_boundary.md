# 开源与第三方边界

## 现状

参赛版从 `GameAssistant` 提交 `d8f3518` 中选择性迁移所需代码，已经形成独立公开仓库：<https://github.com/YYForReal/labtrace-edu-agent>。本仓库代码采用 Apache License 2.0；未把原仓库中的真实课程资料、学生报告、成绩表、签名图片、运行数据或密钥一并迁移。

## 已开放的参赛成果

- 通用实验报告 rubric；
- `GradeTrace` 证据链数据契约；
- 班级学情诊断基线；
- 模拟数据与包验证脚本；
- 评测方法、架构和部署文档；
- 图文 Word 解析、证据定位、原生批注、成绩和教师评语回写代码；
- 可直接运行的 FastAPI + Vue Demo 与 Docker 部署配置。

## 第三方与数据边界

1. 仓库不内嵌 Anthropic 文档技能的 source-available 实现；DOCX XML 诊断改为 Python 标准库直接读取 OOXML 包。
2. Python 与 npm 依赖仍分别受其自身许可证约束；Apache-2.0 不覆盖第三方依赖或模型服务。
3. 公开 Word、截图、图表、分数与案例文本均为人工合成，不来自真实学生作业。
4. 商业模型/API 只作为可选运行时依赖；无密钥确定性模式可以复现相同任务状态、证据契约与教师闭环。
5. 真实课程资料默认只在获得授权后处理，且不进入公开仓库、演示包或遥测。

## 商业 API 与闭源模型披露模板

| 项目 | 填写内容 |
|---|---|
| 服务或模型 | 名称与版本/端点类别 |
| 使用环节 | 文本评分、图片理解或其他 |
| 发送数据 | 字段、是否脱敏、是否包含学生材料 |
| 费用假设 | 每份/每批估算与免费额度依赖 |
| 权限范围 | 只读、上传、存储策略 |
| 可替代性 | 对应的本地开源权重或其他兼容端点 |
| 锁定风险 | 专有协议、上下文、价格或可用性 |
