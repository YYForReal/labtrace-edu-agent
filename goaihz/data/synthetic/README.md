# 模拟数据说明

本目录只存放为 GOAI Demo 人工构造的模拟数据，不包含真实学生报告、姓名、学号、联系方式、成绩或学习记录。

- `demo-assignment-template_实验任务书.docx`：Unity 弹射原型公开合成任务书，可在 Demo 页直接下载。
- `demo-allergen-001_实验报告.docx`：人工合成的过敏原 ELISA 图文报告，作为公开上传样例。
- `demo-game-dev-001_实验报告.docx`：人工合成的 Unity 游戏开发图文报告，作为公开上传样例。
- `grade_records.json`：用于演示班级维度学情诊断。
- `trace_case.json`：用于验证“评分结论 - 证据定位 - 教师复核”数据契约。
- `demo-student-001_实验报告.docx` 与批改示例：仅供解析器和 Word 回写回归测试，不在网页公开样例区展示。

所有 DOCX 的文字、图片、参数和结果均为人工合成；文件不含真实姓名、学号、联系方式、成绩或可识别的作者元数据。诊断数据按通用 rubric 构造匿名样本，并刻意让“分析、验证与误差讨论”成为共性薄弱点。数据只用于功能演示，不代表任何真实班级或学科分布。
